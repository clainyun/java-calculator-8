# java-calculator-precourse

### 구현할 기능 목록

### 1. 기본 구분자
- [ ] 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환
- [ ] 빈 문자열을 입력할 경우 0을 반환

### 2. 커스텀 구분자
- [ ] '//(구분자)\n' 커스텀 구분자 파싱
- [ ] 커스텀 구분자로 분리한 각 숫자의 합 반환

### 3. 예외 처리
- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException 발생
- [ ] 예외 발생 시 애플리케이션 종료

### 4. 사용자 인터페이스
- [ ] Console API를 사용한 사용자 입력 받기
- [ ] 계산 결과 출력 (ex. 결과 : 6)

### 5. 테스트
- [ ] 기본 구분자
- [ ] 커스텀 구분자
- [ ] 잘못된 입력 값(음수, 숫자가 아닌 값) 입력
- [ ] 빈 문자열 0 반환
